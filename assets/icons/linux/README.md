# Linux application artwork

These PNGs are the real logos used by the corresponding desktop programs. They
are shown in Launchpad, Spotlight, the AI Hub launcher and the X11 desktop.

- **Blender** and **Chrome** artwork comes from Wikimedia Commons
  (`Blender_logo_no_text.svg`, `Google_Chrome_icon_(February_2022).svg`) via the
  Wikimedia thumbnail service. Blender and Google Chrome are trademarks of
  their respective owners.
- **GIMP, Inkscape, VLC, LibreOffice Writer, LibreOffice Calc, Geany, Git Cola,
  Files and Text Editor** artwork comes from the
  [Papirus icon theme](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme),
  licensed under GPL-3.0.

The images are bundled only to identify the installed Linux applications.
